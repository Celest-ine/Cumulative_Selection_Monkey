# Cumulative Selection Monkey

The idea of this project is borrowed from the Infinite monkey theorem.
The infinite monkey theorem states that a monkey hitting keys at random on a typewriter keyboard for an infinite amount of time will almost surely type any given text, such as the complete works of William Shakespeare.
The algorithim of this program generates a random phrase and compares the characters in per-oracle position to the phrase entered by the user. The characters that match are locked and only the characters that did not match are generated. The program generates the characters to the slowest character to match and tells the user how long it took in seconds plus how many generations it took to succed.
